Positioning

Normal flow is the default way elements are displayed on a web page.

The float property moves an element to the left or right side of its container, allowing text or other elements to wrap around it.

you use clear to stop elements from wrapping around floated items and to fix layout problems.

The element stays in normal flow but can be moved slightly from its original position using top, bottom, left, or right.
